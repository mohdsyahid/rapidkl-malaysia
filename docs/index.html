🚈 RapidKL Malaysia

Semak laluan dan senarai stesen untuk semua line LRT, MRT, Monorail, BRT, dan bas RapidKL (termasuk bas feeder MRT) — data rasmi GTFS, percuma untuk digunakan oleh mana-mana aplikasi melalui JSON API.

    JSON API percuma

    Data penuh untuk setiap jenis pengangkutan (semua laluan & susunan stesen ikut arah) tersedia sebagai JSON statik. Contoh (LRT/MRT/Monorail/BRT):

    https://mohdsyahid.github.io/rapidkl-malaysia/data/rail.json

    Fail lain: data/bus-kl.json (bas bandar RapidKL), data/bus-mrtfeeder.json (bas feeder MRT), data/feeds.json (indeks semua fail). Data dikemas kini mingguan melalui GitHub Actions, sumber rasmi GTFS static data.gov.my (Prasarana).

    Nota: data ini merangkumi laluan, stesen/perhentian, dan urutan perjalanan sahaja — tiada data tambang/tol. Format GTFS rasmi tidak menyediakan kadar tambang, dan laman rasmi myrapid.com.my disekat semakan bot (captcha), jadi tidak dapat dikikis secara automatik.

    Data dari data.gov.my GTFS static (Prasarana). Projek ini tidak berkaitan secara rasmi dengan Prasarana atau RapidKL.
